本研究仅使用题目给定的DWTS官方赛季周度数据表。为确保后续推断（Q1）与机制对比/仿真（Q2--Q4）在同一数据口径下进行，我们首先将原始宽表转换为“周度面板（weekly panel）+ 赛季层特征（season features）”两张规范化数据集，并进行一致的缺失与异常处理。

\subsection{Data sources and canonicalization}
\begin{enumerate}[
    label = (\arabic*),
    itemindent = 0pt,
    labelindent = \parindent,
    labelwidth = 2em,
    labelsep = 5pt,
    leftmargin = 4.5em
    ]
    \item \textbf{字段解析与类型规范化：}将赛季$\times$周$\times$选手作为唯一键，统一数值字段（评委分、周平均分等）的类型；对字符串字段（选手名、机制名等）去除多余空格并标准化。
    \item \textbf{缺失与退出处理：}对明确“退出/退赛/淘汰”的记录在周度面板中标注退出周；对后续周的缺失分数不做插补（避免引入未来信息），仅用于“在场/不在场”状态更新。
    \item \textbf{一致性检查：}对每周在场人数、淘汰人数、分数范围进行基础审计，保证不存在明显的逻辑冲突（例如同一周多次淘汰、在场选手分数缺失占比异常等）。
\end{enumerate}

\subsection{Q0 canonicalization details (implementation-aligned)}
Q0主线脚本\texttt{src/mcm2026/pipelines/mcm2026c\_q0\_build\_weekly\_panel.py}将官方宽表中的周-评委打分列（形如\texttt{weekX\_judgeY\_score}）解析为长表，并对每位选手在每周的评委分求和得到\texttt{judge\_score\_total}。随后在每个\texttt{season$\times$week}内计算评委分占比\texttt{judge\_score\_pct}（保证在场选手占比和约为1），并给出评委名次\texttt{judge\_rank}（1为最好）。

在场状态\texttt{active\_flag}由当周\texttt{judge\_score\_total>0}判定；退出推断依赖题面\texttt{results}文本字段：
(1) 若\texttt{results}包含\texttt{Eliminated}或\texttt{Withdrew}则提取退出类型；
(2) 若能解析出\texttt{Week k}，则记为\texttt{elimination\_week}；
(3) 若退出周无法解析或与最后一次出场周不一致，则回退为\texttt{last\_active\_week}得到\texttt{exit\_week\_inferred}。
该逻辑保证后续Q1--Q4使用的退出标记只依赖历史周信息，不引入未来信息。

为便于快速复核，Q0同时输出周级与选手级审计表（见\texttt{mcm2026c\_q0\_sanity\_season\_week.csv}与\texttt{mcm2026c\_q0\_sanity\_contestant.csv}），其中包含\texttt{pct\_sum\_active}（应接近1）与退出标记计数等不变量，用于在论文阶段快速排除数据口径错误。

\subsection{Feature construction for downstream tasks}
在周度面板中，我们构造了以下关键特征（在Q1--Q4反复使用）：
\begin{enumerate}[
    label = (\arabic*),
    itemindent = 0pt,
    labelindent = \parindent,
    labelwidth = 2em,
    labelsep = 5pt,
    leftmargin = 4.5em
    ]
    \item \textbf{评委维度：}当周评委总分与其在当周的百分位/名次（用于“评委信号”）。
    \item \textbf{观众维度（可观测代理）：}由当周淘汰结果与评委信号共同约束，形成观众偏好强度的可推断结构（用于Q1的后验推断与不确定性量化）。
    \item \textbf{机制相关指标：}针对Percent与Rank两种投票合成方式，构造每周的机制得分、相对差异、以及跨周可比较的度量。
\end{enumerate}

\subsection{Reproducibility and audit artifacts}
为保证“论文叙述---模型输入---输出图表”三者一致，我们在Q0阶段将原始DWTS宽表转换为两张\textbf{规范化主线数据集}，并提供对应的审计表用于快速核对。

\paragraph{Canonical processed datasets (Q0 outputs)}
\begin{enumerate}[
    label = (\arabic*),
    itemindent = 0pt,
    labelindent = \parindent,
    labelwidth = 2em,
    labelsep = 5pt,
    leftmargin = 4.5em
    ]
    \item \texttt{../data/processed/dwts\_weekly\_panel.csv}: 周度面板（\textbf{2777$\times$18}）。该表包含后续Q1--Q4所需的核心字段：\texttt{judge\_score\_total}, \texttt{judge\_score\_pct}, \texttt{judge\_rank}, \texttt{active\_flag}（以上核心字段缺失为0）。
    \item \texttt{../data/processed/dwts\_season\_features.csv}: 赛季层特征（\textbf{421$\times$11}）。该表提供静态协变量（年龄、行业、地区、舞伴等）用于Q3解释模型。
\end{enumerate}

\paragraph{Missingness and exit-type sanity checks}
基于主线 processed 数据表的统计审计：周度面板整体缺失率约为\textbf{4.54\%}，赛季特征表整体缺失率约为\textbf{2.42\%}；按选手赛季结果推断的退出类型分布为\texttt{eliminated=298}, \texttt{withdrew=10}, \texttt{unknown=113}。这些统计用于约束后续推断的“信息量”与边界条件（例如多退出周、退赛周等）。
